>> B3: Describe your code for reading and writing user data from the
>> kernel.
1. read : first, check if esp that we need are in the user memory. then, if fd == 0, 
wait in the for loop until input has reached readsize. Otherwise, get the file 
accoring to the fd. If not, return -1. Now, check if all of the data in the buffer is in the user memory.
Now, use file_read(), which will return the number actually read, and return it to eax.

2. write : similar to read, first, check if esp that we need are in the user memory. then, if fd == 1, 
use putbuf. Otherwise, get the file accoring to the fd. If it is null or file executing, return 0. else, return -1. 
check if all of the data in the buffer is in the user memory.
Now, use file_write(), which will return the number actually writen, and return it to eax.
